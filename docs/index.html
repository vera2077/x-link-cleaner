1

Scope

Every link copied from X carries a query string identifying how and where it was shared. This document describes what happens to those links once the extension is installed. It applies to links copied on x.com and twitter.com, including their mobile web variants.

It does not describe the extension's internals, only its observable output.

2

Link transformation

X's Copy Link control produces a URL whose query string tracks the share. The extension replaces what reaches the clipboard.

  1. 2.1 The query string is removed in full. No parameters are filtered selectively; the entire component is dropped.
  2. 2.2 The path and any fragment are preserved exactly as X wrote them.
  3. 2.3 When copied text contains a link rather than being one, the link inside the text is rewritten and the surrounding text is left alone.
  4. 2.4 Links to hosts other than X and Twitter are not touched.
3

Host substitution

A copied link keeps its original host unless a replacement is configured. When one is set, only the hostname changes; nothing else about the URL is reconsidered.

4

Obtaining a copy

Firefox

Signed and distributed through addons.mozilla.org. Updates apply automatically. Also listed for Firefox for Android 142 and later, where it appears in the browser menu.

Add to Firefox

Chromium browsers

Chrome, Edge, and Brave require an unpacked build, because the Chrome Web Store levies a one-time developer registration fee. Download the archive, extract it, open chrome://extensions, enable Developer mode, and choose Load unpacked.

Download the archive

Chrome asks about developer-mode extensions at each start. The userscript avoids that.

Userscript

Runs under Tampermonkey, Violentmonkey, or ScriptCat on any supported browser, mobile included. Same behaviour, different delivery.

5

Non-goals

Stated plainly, because these are the cases where the extension will disappoint someone.

  1. 5.1 It does not make a front-end trustworthy. Choosing fixvx, fxtwitter, or vxtwitter means whoever opens your link visits that service instead of x.com. The extension itself contacts nothing, but your recipients do.
  2. 5.2 It does not repair X's mobile menu. The Copy Link item comes and goes in the mobile web interface, so on phones the copy-event path does most of the work.
  3. 5.3 It does not validate the destination. A host that fails validation is discarded and the original retained. Nothing is checked for reachability.
