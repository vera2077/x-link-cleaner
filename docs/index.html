Copy the link.
Not the tail.

X appends tracking parameters to every link you copy. This extension removes them, then points the link at whichever domain you prefer.

v3.0 Firefox 109+ · Chrome · Android

What comes off

The query string is dropped entirely — ?s=20&t=Gv3Fy2Xb and everything like it. What survives is the part that identifies the post: the author handle and the status path.

If you set a base domain, only the hostname is swapped. Path, fragment, and structure stay exactly as X wrote them.

Add to Firefox

Also available for Firefox for Android 142+, from the browser menu.

Chrome, Edge, Brave

The Chrome Web Store charges a one-time developer fee, so this ships unpacked. Download the zip, extract it, then load it:

  1. Open chrome://extensions
  2. Turn on Developer mode
  3. Click Load unpacked and pick the extracted folder

Download the zip

Chrome will ask whether to keep developer-mode extensions on each start. If that bothers you, use the userscript instead.

Any browser, via userscript

Needs Tampermonkey, Violentmonkey, or ScriptCat. Same features, no developer mode, and it works on mobile.

Where it stops

  • Front-end domains are third parties. Choosing fixvx, fxtwitter, or vxtwitter means whoever opens your link visits that service instead of x.com. The extension contacts nothing, but your recipients do.
  • X's mobile menu is inconsistent. The Copy Link item comes and goes in the mobile web UI, so on phones the copy-event path does most of the work.
  • It only runs on x.com and twitter.com. Links copied from elsewhere are untouched.
  • Invalid domains fall back silently. Type something that isn't a domain and the original host is kept rather than saved.
